# Soybean Admin Go 测试

本目录包含 Soybean Admin Go 项目的测试用例，主要用于测试各个API的功能是否正常。

## 测试结构

测试目录结构如下：

```
test/
├── api/                  # API测试用例
│   ├── api_api_test.go   # API管理相关API测试
│   ├── front_api_test.go # 前端路由相关API测试
│   ├── system_manage_api_test.go # 系统管理相关API测试
│   └── user_api_test.go  # 用户相关API测试
├── testutil/             # 测试工具包
│   └── testutil.go       # 测试辅助函数
├── main_test.go          # 测试入口点
└── README.md             # 测试说明文档
```

## 测试内容

测试用例覆盖了以下几个方面：

1. **用户API测试**：测试登录、刷新令牌、获取用户信息、修改密码等功能。
2. **前端路由API测试**：测试路由存在检查、获取固定前端路由、获取用户前端路由等功能。
3. **系统管理API测试**：测试菜单管理、角色管理、用户管理等功能。
4. **API管理API测试**：测试获取所有API、获取角色的API权限等功能。

## 运行测试

### 前提条件

在运行测试之前，请确保：

1. 已经设置好数据库，并且数据库中有测试所需的基础数据。
2. 已经配置好Redis，用于缓存测试。
3. 项目配置文件（config.toml）已正确配置。

### 运行所有测试

在项目根目录下运行：

```bash
go test ./test/... -v
```

### 运行特定测试

运行特定测试套件：

```bash
go test ./test/api -run TestUserAPI -v
```

运行特定测试用例：

```bash
go test ./test/api -run TestUserAPI/TestLogin -v
```

## 注意事项

1. 测试用例中使用了模拟的JWT令牌，在实际环境中可能需要调整。
2. 测试用例假设数据库中已有一些基础数据，如果数据库为空，某些测试可能会失败。
3. 某些测试用例可能需要特定的权限设置，请确保测试用户具有足够的权限。

## 扩展测试

如果需要添加新的测试用例，可以参考现有的测试文件结构，创建新的测试文件或在现有文件中添加新的测试方法。

测试工具包（testutil）提供了一些通用的测试辅助函数，可以在新的测试用例中重用这些函数。
